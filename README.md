# Consolidated Intelligence Platform

AI-powered criminal network analysis system — Smart India Hackathon 2026,
Problem Statement **SIH26189**. Team **CARIBBEAN**.

Ingests FIRs, surveillance reports, intelligence-agency reports, call
detail records, and financial transaction records; resolves identities;
builds a relationship graph; surfaces influential entities and hidden
structural patterns (mule-account layering, burner-SIM rotation,
recruiter-transporter-receiver trafficking chains); and hands investigators
evidence-backed leads — never an automated accusation.

Governing principle: **DATA → RELATIONSHIP → PATTERN → LEAD → EVIDENCE →
HUMAN DECISION.** It never becomes DATA → AI → PERSON SCORE → GUILTY.

All data in this repository is synthetic, generated by
`backend/app/data_generation/generator.py` with a fixed random seed. No
real case data is used.

## Repository layout

```
backend/    FastAPI + SQLite + NetworkX + spaCy — ingestion, resolution,
            graph analytics, hidden-structure detectors, evidence engine,
            tamper-evident audit chain, RBAC
frontend/   React + TypeScript + Vite — investigator dashboard SPA
```

[`Investigator_Briefing_Guide.pdf`](Investigator_Briefing_Guide.pdf) for a

## Running locally

**Backend**
```bash
cd backend
python -m venv venv
venv\Scripts\activate        # macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
python -m app.pipeline       # generates synthetic data, builds the graph
uvicorn app.main:app --port 8000
```

**Frontend**
```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`.

**Run the test suite**
```bash
cd backend
venv\Scripts\activate
python -m pytest tests/ -v
```
(This regenerates the dataset with a fixed seed before running, resetting
any UI-made dispositions/reviews back to the clean planted state.)

## Configuration

**Backend** (environment variables, all optional):
- `CIP_JWT_SECRET` — JWT signing secret (set a real one in production)
- `ALLOWED_ORIGINS` — comma-separated CORS allow-list (defaults to `*`)

**Frontend** (build-time, via `.env.local` or your host's env settings —
see `frontend/.env.example`):
- `VITE_API_BASE` — the deployed backend's `/api` URL

## Deployment

This is a two-service app: a stateful Python backend (SQLite file, an
in-process graph, a background pipeline run) and a static frontend build.
They deploy separately:

- **Frontend** → Vercel or Netlify. Build command `npm run build`, output
  directory `frontend/dist`, with `VITE_API_BASE` set to the backend's URL.
- **Backend** → a host that runs a persistent process with a writable disk
  (Render, Railway, Fly.io, or a small VPS) — not a serverless/edge
  platform. SQLite plus the periodic full-pipeline regeneration don't fit a
  stateless function model. Start command: `python -m app.pipeline &&
  uvicorn app.main:app --host 0.0.0.0 --port $PORT` (see `backend/Procfile`).
  Set `ALLOWED_ORIGINS` to the frontend's deployed origin once both are live.

## Known limitations

See the full report for details: SQLite is intentionally dev-grade
(production graph-database migration is documented as future work only);
the missing-link recovery feature reports a genuinely low recall on this
sparse synthetic graph, by design not tuned up; and no real case data is
used anywhere in this system.
